# Sistema de Gerenciamento de Biblioteca

Projeto acadêmico desenvolvido durante meu aprendizado em Python, com o objetivo de aplicar lógica de programação e programação orientada a objetos em uma situação prática.

## Objetivo do projeto

O sistema representa o funcionamento básico de uma biblioteca, permitindo organizar livros, membros e endereços. Também permite registrar empréstimos e devoluções de livros.

Ainda há muitas funcionalidades para adicionar. Pretendo usar este código como base para implementar melhorias e ampliar meu conhecimento.

## Tecnologias utilizadas

- Python
- Programação Orientada a Objetos (POO)
- Listas e estruturas de dados
- Classes e métodos
- UUID para geração de identificadores únicos

## O que aprendi

Também aprofundei meus conhecimentos em programação orientada a objetos, criação de classes, métodos, listas, organização de dados e lógica de programação. Além disso, o projeto reforçou a importância de planejar a estrutura de uma aplicação antes de adicionar novas funcionalidades.
